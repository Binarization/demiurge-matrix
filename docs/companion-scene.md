# 陪伴场景控制

本场景继续使用原来的 VRM、Gaussian Splat、加载页面和语音链路。模型已经有完整 humanoid 骨骼和春骨；新增动作直接驱动 normalized bones，不重绑权重，也不修改原始模型。

## 空间与碰撞

`src/avatar/scene/layout.ts` 的坐标是在 Splat 缩放 `[2,2,2]` 之后的世界坐标。读取本地 Splat 的高不透明度点：前景铺装主要位于 y=2.3–2.4，树干高密度点位于 x=1.5、z=7.5 附近。以 y=2.38 建立局部水平行走面；脚踝离地目标为 0.075，按当前模型的骨骼尺寸校准模型原点。这里是前景活动区域的人工碰撞代理，不是整张 Splat 的精确重建。

- 行走区：x=-2.65…0.25，z=7.45…9.35，角色水平半径 0.16。
- 树干、右侧石边和新增座凳都有盒体代理。路径以不超过 0.04 的间距检测，避免越过薄障碍。
- 座凳是实际可见几何，座面 y=2.79。坐下先绕到前方，落座时只允许这段受控动作进入座面空间；起身后退出座面再回位。
- `?scene-debug=1` 显示地面网格与碰撞盒；正常界面不显示开发辅助几何。

## 动作与骨骼

`BodyDirector.ts` 保存手工姿态关键帧并做平滑插值：伸懒腰、挥手、摸头回应；走近、回位和去座凳使用受限路径，由实时移动控制器计算速度与转向，不再按整段动作的时间百分比移动。`ik.ts` 的两段式 IK 根据真实大腿、小腿长度计算膝盖和脚的位置，并限制不可达目标。坐姿的手移至腿上，伸手动作使用同一 IK 解算器。

更新顺序：撤销上一帧微动作 → 恢复上一帧覆盖前的基础姿态 → VRMA mixer → 全身姿态与 IK → 表情/口型与微动作 → VRM 更新。全身动作拥有姿态时，上一版微动作逐渐淡出，避免抢同一骨骼。打断会清空当前动作并平滑回到待机；坐着时保持坐姿，站起是单独动作。

这是手工关键帧和运动学控制，没有新增动作生成网络、云端推理或摄像头权限。裙摆仍使用现有蒙皮与春骨，没有增加布料碰撞求解；极端姿态和全部背景区域不在此版活动范围内。

## 镜头与互动

- 顶部“一起”入口提供陪伴、全身、近景三个视角，以及八个动作；同样支持键盘操作。
- 移动/伸展时镜头自动留出空间；结束后恢复先前预设。手动拖动或缩放会取消自动移动和待恢复镜头。减少动态效果时镜头直接到达目标。
- 头、手、上身分别有随骨骼移动的命中体。点击/划过头部触发回应；点击手部触发伸手；点击上身挥手。角色之外的拖动仍用于 OrbitControls。取消触摸、多指输入不会提交动作。
- 同时只执行一个全身动作。互动不调用 LLM；语义指令使用首个 `<emote body="sit" camera="full"/>` 的白名单属性，有语音时等待真实播放开始。
- 完成或打断事件存入本地会话的 `sceneEvents`（最多20条），并在下次 LLM 请求中提供最近6条。界面显示实际动作状态，不把预制动作写成角色说过的台词，也不把取消记录为完成。

## 验证

`bun test` 覆盖路径碰撞、IK、命令白名单、镜头手动接管、语音等待和叠加姿态恢复。启动开发服务后，运行 `UI_TEST_URL=http://127.0.0.1:5177/ node scripts/check-scene-browser.mjs` 检查真实骨骼、各动作、坐下/起身/回位、头部拖动和手部点击、持久化事件以及手机布局。截图写入 `/tmp/cyrene-stage-*.png`。`scripts/inspect-scene.mjs` 可输出实测骨骼坐标。

## 实时步态（修正）

`LocomotionController.ts` 把路线转换为实时移动意图，采用 120 Hz 固定步长：

- 根节点按加速度、制动距离和面向误差计算实际速度。大角度转向时先转身，再开始行走；到达后通过原地踏步转回伙伴方向。
- 双脚有独立的支撑/摆动状态。支撑脚锁在世界坐标；根据骨盆位移、速度预测和朝向误差选择下一次落脚点。摆动脚在抬起时确定目标并完成落地，中途打断不会重置脚的位置。
- 每个模拟步检查角色碰撞和支撑腿可达距离；步幅有上限，双脚保留短暂双支撑期。碰撞阻挡作为失败结束，不记录为完成。
- 骨盆降低为屈膝留出余量，并随步态做小幅重心转移；摆臂与胸/骨盆的反向旋转按实际行走距离驱动。脚部 IK 的膝盖弯曲方向跟随角色朝向，脚掌旋转保留各自落地朝向。
- 路线结束且双脚收稳后，才开始坐下等后续动作；原始 VRMA 待机在全身控制结束后淡入。当前地面采样仍是校准后的局部平面，并非任意地形导航。

验证额外覆盖 30/60/120 Hz 一致性、支撑脚零目标漂移、回头行走、打断落脚、碰撞释放，以及按真实角色腿长建立的骨架上“走近→回位→坐下→站起→回位”的 IK 可达性。

## 闲时生活

伙伴不说话时，她自己也在这片小天地里过日子，不调用 LLM：

- **小动作**：`CompanionMotion` 在 `idle` 状态持续约 14–24 秒后，每隔约 20–45 秒随机做一个叠加动作：望向一侧、抬头看天、歪头出神、轻叹一口气。进入倾听/思考/说话或出现手势时立即淡出；坐姿、全身动作和“减少动态效果”下不做。
- **身体动作**：`src/lib/idle-life.ts` 决定何时自发行动。静默 2.5 分钟后可伸懒腰；超过 5 分钟且不在近景时，一半机会改为去长椅坐下；坐满 6 分钟起身，15 秒后走回原处；两次自发动作间隔至少 3 分钟。Core 每 5 秒检查一次，只有在页面可见、没有回复/朗读/语音输入、输入框为空且没有其他动作时才执行。指针、键盘、滚轮、触摸、发送消息和切回页面都算伙伴活动。
- **安静模式**：`playBodyAction(action, { quiet: true })` 不切全身镜头、不弹动作提示，也不禁用“一起”面板；动作结束后若伙伴没有手动操作镜头，按当前视角轻轻回正。伙伴请求的动作（按钮、触摸、`<emote body>`）会立即接管；若她正在迈步，等脚落稳后接上。
- 完成的自发动作以“自己…”记入 `sceneEvents`（如“自己坐一会儿”），被打断的不记录；提示词说明这类事件可以自然提起。

浏览器检查：`UI_TEST_URL=http://127.0.0.1:5177/ node scripts/check-idle-browser.mjs`。脚本通过偏移页面内 `Date.now` 模拟数分钟静默，验证小动作、镜头不跳、长椅→起身→回位循环、镜头回正、伙伴请求接管与事件记录；截图写入 `/tmp/cyrene-idle-*.png`。
